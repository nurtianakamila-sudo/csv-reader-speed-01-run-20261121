A faster drop-in for make.fun's own csv-reader 1.0.0: it answers exactly as csv-reader does on every case, reading broken CSV files with indexOf-based scanning instead of one character at a time — about 7x faster than the house baseline on the practice set, with identical answers on all 6 practice cases, 218 hand-built edge cases and 1,600 fuzzed inputs.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
